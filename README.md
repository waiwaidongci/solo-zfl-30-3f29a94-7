# 水下考古潜水记录

在原有标记工具上增加**证据链**与**风险复核**：标记按 采集 → 复核 →（退回补证 ⇄ 复核）→ 入库 流转，全程留痕、可撤销重做，手机与桌面均可走完全流程。

## 启动

- 直接双击打开 `index.html`（`file://` 可用，无需构建）；或
- `python3 -m http.server 8321` 后访问 `http://127.0.0.1:8321/`。

首次打开写入两条示例数据；数据存于浏览器 `localStorage`（键 `zfl30Marks`，沿用旧键）。

## 结构（数据逻辑与页面分离）

| 文件 | 职责 |
| --- | --- |
| `js/store.js` | 纯数据层，无 DOM：状态机、五类风险校验、审计日志、撤销/重做、批量事务、持久化与旧数据迁移。浏览器全局 `MarkStore`，Node 可 `require` |
| `js/app.js` | 页面层：渲染与交互，所有写操作经数据层入口 |
| `index.html` | 结构与样式（桌面双栏 / ≤980px 单列） |
| `tests/store.test.js` | 数据层自动化测试（node:test，零依赖） |

## 规则说明

**流转**：采集 →(提交复核)→ 复核 →(通过入库)→ 入库；复核 →(退回补证，**必填原因**)→ 退回补证 →(**补充证据后**重新提交)→ 复核。退回时快照证据，未改动证据不能再次提交；退回后在表单里改完证据**直接点「重新提交复核」即可**，修改与状态变更同一事务提交，无需先单独保存。入库为终态：已入库标记不能修改、删除或再流转，该限制由数据层强制（绕过页面直接调写接口同样被拒，注入 `status` 字段也会被清洗）；唯一合法出口是撤销入库操作。

**每条标本记录**：采样袋号、照片说明、处理人、保管位置（证据链四件）+ 编号/类型/潜次/深度/坐标/朝向/保存状态/备注。

**五类风险分别拦截**（保存或流转时校验，提示语各自独立）：

| 拦截 | 规则 |
| --- | --- |
| 编号重复 | 编号全库唯一 |
| 位置越界 | 坐标须在 0~100 |
| 深度超限 | 深度 ≤ 40m（`DEFAULT_LIMITS.maxDepth` 可调） |
| 证据缺失 | 提交复核/入库前四件证据必须齐全 |
| 保管冲突 | 保管位置全库唯一 |

**批量操作**：列表勾选后批量提交复核/通过入库；整批先在草稿上校验，**任一失败则全部不落地**（无半截保存、无审计垃圾），成功则为一步、可一次撤销。

**留痕**：每次变更记录操作人、时间、原因与逐字段前后值，撤销/重做与普通变更一样完整留痕（含前后值 diff），见侧栏「变更记录」视图。操作人必填（顶栏输入，本地记忆）。`Ctrl/⌘+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。

**导出**：顶栏导出 JSON（含版本号、标记、审计日志）。

**旧数据迁移**：旧版纯数组格式（深度带 `m`、无状态/证据）加载时自动升级为 v2 信封：状态置「采集」、深度转数值、证据字段补空，旧标记可正常打开编辑，补证据后继续走流程。
